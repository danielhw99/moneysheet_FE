# 계정 팝업 화면 검증

UR04: 비밀번호 변경·회원 탈퇴 팝업은 계정 전용 CSS로 앱 프레임과 뷰포트 안에 표시한다.
사용 가이드의 공통 팝업 스타일은 변경하지 않는다.

검토 화면 크기: 1280×900, 390×844, 360×500, 640×320.

1. MY → 계정관리 → 비밀번호 변경을 연다.
2. 팝업 좌우가 앱 프레임을 넘지 않고 위아래가 뷰포트를 넘지 않는지 확인한다.
3. 현재·새 비밀번호·확인을 입력하고 오류 문구가 표시된 상태에서도 내부 스크롤로 제출·취소에 접근한다.
4. 취소 후 다시 열기, Esc 닫기, 회원 탈퇴 팝업 열기·취소를 확인한다.
5. 실제 계정으로 검토할 때 비밀번호 변경·탈퇴는 실제 데이터 변경이므로 주의한다.

자동 브라우저 검토에서는 API 응답을 격리 mock으로 처리하고 실제 계정·DB를 변경하지 않았다.
가상 키보드가 실제 기기에 표시된 상태는 별도 수동 확인 대상이다.
