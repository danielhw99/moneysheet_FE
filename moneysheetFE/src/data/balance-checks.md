# UR02 실제 계좌 잔액

실제 잔액과 잠금 상태는 Daily 화면 메모리가 아닌 사용자·날짜별 서버 데이터다.
기존 README의 비교 잔액을 FE 전용 상태라고 설명한 부분은 UR02부터 이 문서로 대체한다.
잠금 해제를 서버에 저장하고, 편집 후 다시 잠글 때 금액과 잠금 상태를 저장한다.
금액은 null(미입력)과 0원을 구분한다. 금액을 비우고 잠그면 미입력으로 저장한다.
실패 시 폼 값과 편집 상태를 유지한다. 날짜별 조회 실패 시 재시도할 수 있다.
요약 계산에 반영하지 않는다. GET/PUT /daily-balance-checks/{date}를 사용한다.
다른 기기에서는 화면 진입·재조회 시 최신 저장값을 확인한다. 실시간 푸시는 제공하지 않는다.
BE V4 마이그레이션과 API 배포 후 FE를 배포한다.
