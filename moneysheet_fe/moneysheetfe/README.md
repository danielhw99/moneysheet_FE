# MoneySheet Frontend App

이 디렉터리는 MoneySheet 프론트엔드 실제 애플리케이션 루트입니다.

## Convention Summary

- 공식 문서: [../../../docs/planning/project-convention.md](../../../docs/planning/project-convention.md)
- Branch: `feature/<Issue_Number>-<Domain>`
- Commit: `[<Prefix>] #<Issue_Number> <Description>`
- Pull Request: `[<Prefix>] #<Issue_Number> <Description>`

## Running the Code

- `npm i`
- `npm run dev`

## Working Rules

1. issue를 먼저 생성합니다.
2. feature branch에서 작업합니다.
3. commit / push / PR 전 실행 오류를 확인합니다.
4. PR은 `develop`으로 squash merge 합니다.
